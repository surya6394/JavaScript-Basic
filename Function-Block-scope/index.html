Function and Block Scope

Function Scope

  1. Variable defines with "var" into a function is accessiable through out whole function.
  2. If we define in block {} like for, if, while within a function are also accessiable outside that block and whole function.


  1. Variable defines using let, const into a block like {} if, for, while cann't be accessiable outside of block.
  2. Variable defines in function can be accessiable in the blocks available in function.
